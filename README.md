# humancollabintraday

OpenMausBot skill for crypto intraday human-collab trading (VP/OF).

## Import in desktop MausBot

1. Bot settings → Skills
2. Paste: `https://github.com/<OWNER>/mausbot-skill-humancollabintraday`
   or the `SKILL.md` blob URL after push
3. Review, then enable

## Name

`humancollabintraday` (lowercase, no spaces)

## Notes

- Does not place orders
- Pair with working folder containing `RULES_人机协同.md` and `工具箱_Bot调用清单.md`
